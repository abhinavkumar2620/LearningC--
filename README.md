# Happyc++

This repository contains beginner C++ programs and practice exercises.

## Folder structure

- `basics/` - basic C++ examples and variable practice

## How to run

1. Open a C++ source file in the `basics` folder.
2. Compile it with a C++ compiler, for example:

```bash
g++ basics/basic.cpp -o basic
./basic
```

3. Or compile any other file similarly.

## Notes

This project is intended for learning basic C++ concepts such as variables, output, and updates.
